📖 项目简介

本项目是一个纯静态的班级博客，采用绝对对称的排版与苹果风毛玻璃UI，拥有动态背景平移、FPS 实时监控、自定义字体切换、深浅色主题随动以及极具特色的“蓝屏关服维护”机制。

本项目已通过 GitHub Pages 成功部署上线，任何人都可以通过上述在线地址访问，无需购买服务器或域名，完全零成本。

🚀 快速上手

1. 启动本地预览

由于首页使用了 fetch 读取本地 JSON 文件，浏览器会拦截跨域请求。必须在项目根目录启动本地服务器：

# 进入项目目录
cd "/storage/emulated/0/HTML/9月11日/2/"

# 启动 Python 服务器
python -m http.server 8000

2. 访问地址

在浏览器中打开 http://localhost:8000 即可预览首页。

3. 在线访问

项目已部署至 GitHub Pages，在线地址：https://pibo0608.github.io/Pibo-ClassHub/

🛠️ 核心功能与维护流程

蓝屏维护机制（关服/开服）

通过 data/config.ini 中的总控开关，可以实现全站蓝屏维护。

参数 说明 默认值
maintenance 1 代表蓝屏维护，0 代表正常显示 0
  • 关服：将 maintenance = 0 改为 maintenance = 1，全站瞬间进入蓝屏状态。
  • 开服：将 maintenance = 1 改回 maintenance = 0，刷新页面即可恢复正常。

数据更新（静态维护）

  • 值日表：修改 data/duty.json 中的 duty 数组与 dutyRules 文本。重要人名（如“梅智慧”）会自动高亮显示。
  • 课程表：修改 data/courses.json，包含每节课的起止时间、科目、教师等。
  • 班级干部：修改 data/personnel.json，支持超链接弹窗展示职务与职责。
  • 学生名单：修改 data/student.json，用于随机点名器。
  • 作业看板：修改 data/homework.json，在首页展示今日作业。
  • 蓝屏文案：修改 data/403.json，自定义蓝屏随机停止代码与进度信息。

🌐 GitHub Pages 部署指南

1. 部署方式

本项目使用 GitHub Pages 的分支部署方式，直接从 main 分支的根目录（/root）发布站点，无需额外的构建步骤。

2. 部署配置步骤

  1. 将代码推送到 GitHub 仓库（pibo0608/Pibo-ClassHub）的 main 分支。
  2. 进入仓库页面，点击 Settings → Pages。
  3. 在 Source 下选择 Deploy from a branch。
  4. 分支选择 main，目录选择 /(root)，点击 Save。
  5. 等待约 1-2 分钟，GitHub 会自动构建并发布站点。

3. 访问地址

https://pibo0608.github.io/Pibo-ClassHub/

4. 自定义域名（可选）

  1. 在仓库根目录创建名为 CNAME 的文件（无后缀），内容为你的域名（如 blog.example.com）。
  2. 在 DNS 服务商处添加 CNAME 记录，指向 pibo0608.github.io。
  3. 进入仓库 Settings → Pages → Custom domain，填入域名并保存。
  4. 等待 DNS 生效后，勾选 Enforce HTTPS 启用 SSL 加密。

⚠️ 开发与测试须知

提示：禁止直接双击 HTML：必须通过 Python 等本地服务器访问，否则会出现 CORS 跨域错误或页面白屏。
  1. 缓存问题：修改 config.ini 后如果网页没反应，按 Ctrl + F5 强制刷新。
  2. 编码要求：所有 .json、.ini 文件必须保存为 UTF-8 格式。
  3. GitHub Pages 缓存：部署到 GitHub Pages 后，更新内容可能需要几分钟才能在全球 CDN 节点生效，属正常现象。
